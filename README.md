# Completely Customized Custody

Completely Customized Custody (CCC thereafter) is an agentic crypto asset custody solution. It can leverage all known custody technologies while keeping the requirement for domain knowledge and the complexity of operation from the user. It composes a customized system out of siloed solutions according every user's unique requirements and resources.

Why do we need to combine technologies?

- To avoid the risk of single technology, such as tampered hardware wallets and incorrect random number generator in software wallets.

- To be more secure by being more sophisticated. A wallet with more fine-grained controls is safer than the one with a binary open/closed state.

CCC works as three phase process.

1. The architect agent interacts with the user via conversation and diagrams to understand the user's needs and resources. It then generate a design specification.

2. The builder agent takes the spec to build and deploy the solution.

3. The user use the solution to sign transactions.
